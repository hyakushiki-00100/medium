# スタイルガイド

Medium 出品作品の表記・トーンを揃えるためのガイドです。迷ったらこのガイドに従います。

## トーン

- 読者に語りかける、丁寧だが硬すぎない文体
- 専門用語は初出で簡単に説明する
- 一文は短く。1文1メッセージを心がける

## 表記ルール

- 日本語と英数字の間は半角スペースを入れる（例: Medium の記事）
- 数字は原則半角
- 箇条書きの文末は体言止め、または「。」で統一（記事内で混在させない）
- 見出しは名詞句または問いかけで簡潔に

## 構成の基本

1. **導入** — 読者の課題・興味を掴む（数段落）
2. **本論** — 見出しごとに1つの論点。図・コード・例を添える
3. **まとめ** — 要点の再確認と次のアクション

## 画像・引用

- アイキャッチは1作品1枚を基本とする
- 画像は出典・ライセンスを必ず確認し、企画書に記録する
- 引用は出典を明記し、引用範囲を最小限にする

## やらないこと

- 根拠のない断定
- 過度な煽り表現
- 他者の文章の無断転載

# 役割分担

チームは以下の役割で作品制作を進めます。1人が複数の役割を兼ねても構いません。

## 役割一覧

### 編集リード（Editor Lead）
- 企画の承認と全体の品質管理
- スケジュールと優先順位の調整
- スタイルガイドの整備

### ライター（Writer）
- 企画書の作成と執筆
- レビュー指摘への対応
- 公開後の振り返り

### レビュアー（Reviewer）
- 構成・内容・表記のレビュー
- 事実確認（ファクトチェック）
- 公開前チェックリストの確認

### ビジュアル担当（Visual）
- アイキャッチ・図版の作成
- 画像の権利確認（フリー素材の出典管理を含む）

## 責任分界（RACI 簡易版）

| ステップ   | 編集リード | ライター | レビュアー | ビジュアル |
|-----------|:---------:|:-------:|:---------:|:---------:|
| 企画       |    A      |    R    |     C     |     -     |
| 承認       |    R      |    C    |     -     |     -     |
| 執筆       |    C      |    R    |     -     |     C     |
| レビュー   |    A      |    C    |     R     |     C     |
| 公開       |    A      |    R    |     C     |     C     |

R=実行 / A=承認 / C=相談 / -=関与なし

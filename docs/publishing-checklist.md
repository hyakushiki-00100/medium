# 公開前チェックリスト

Medium への公開前に、以下をすべて満たしていることを確認します。

## 内容

- [ ] タイトルが内容を正しく表し、読みたくなる
- [ ] 導入で読者の課題・興味を掴めている
- [ ] 見出しごとに論点が1つに絞られている
- [ ] まとめで要点と次のアクションが示されている
- [ ] 事実・数値・引用の出典を確認した（ファクトチェック済み）

## 表記

- [ ] [スタイルガイド](style-guide.md)に準拠している
- [ ] 誤字脱字・表記ゆれがない
- [ ] リンク切れがない

## ビジュアル

- [ ] アイキャッチ画像を用意した
- [ ] 画像のライセンス・出典を確認した
- [ ] 図版が本文と対応している

## メタ情報

- [ ] タグ（Medium の Topics）を設定した
- [ ] メタ情報の `status` を `published` に更新する準備ができている
- [ ] 公開後に URL を作品ファイルへ追記する

## 最終確認

- [ ] レビュアーの合意を得た
- [ ] 公開日時を決めた
